◈ Guide — Correspondence Exploration

Welcome to Risala for Correspondence Exploration, an epistolary corpus explorer developed as part of the ObTIC project (Sorbonne Université, 2026).

◈ Letters
List of filtered letters, sorted by date. Click on a card to open the detail panel — full text, metadata, clickable entities. The PRS / LOC / OBJ tags instantly filter the current selection.
◎ Network
Correspondence graph between senders (colored nodes) and cited persons (green nodes). Edge thickness is proportional to the number of letters exchanged. Use Focus on to isolate an actor, and drag nodes freely.
◻ Map
Geographic map of correspondences. Each active place is represented by a circle whose radius is proportional to the number of letters. Dashed lines indicate sending flows (sender → recipient). Requires geographic coordinates in the corpus.
⊣ Timeline
Timeline of letters. Three views: Points by month (one point per letter on a line per sender), Histogram by year, Histogram by month. Drag horizontally to navigate. Click on a point or bar to open the corresponding letters. The Period filter in the sidebar restricts the years displayed.
≋ Word Cloud
Most frequent terms in the current selection. Size is proportional to frequency. Adjust the word count with the slider, and filter by language (All / Arabic / French). Common stopwords (Arabic and French) are automatically removed.
⊙ Clusters
Automatic grouping of letters by textual similarity (k-means on TF-IDF, 2D PCA projection). Each color corresponds to a cluster. Choose the number of clusters and click Cluster. Requires a corpus with sufficiently varied texts.
↓ Export CSV
Exports the current selection in CSV format (UTF-8 with BOM, Excel-compatible). All fields are included: identifier, dates, sender, recipient, places, text, entities.
⧗ Filters
All filters (sender, recipient, places, period, entities) apply in real time across all views. The Period filter uses a double slider: drag both ends to define a year range. The RESET button resets all filters.
